\section{Interpretation Advice}

This file is a snapshot, not a substitute for \texttt{master\_config.py}. The important current design fact is that the project now uses limited binary-search capacity testing. Each tested agent number follows a one-success-out-of-five pass rule, and each mapping retains one successful capacity run per configuration. As a result, the detailed main-experiment logs report direct run values rather than averages over three successful runs.
