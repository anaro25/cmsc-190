\section{Interpretation Advice}

This file is a snapshot, not a substitute for \texttt{master\_config.py}. The important current design fact is that the project now uses limited binary-search capacity testing with paired temp criteria. The classical-side search reports the highest tested agent number where classical solves and cyclic still beats classical on the same setup. The cyclic-side search reports the highest tested agent number where cyclic solves and beats classical on the same setup. In both cases, the temp comparison uses time computation halted and conflicts at halt. The downward-move limit is enforced only after the search has found at least one passing agent number, so configurations whose first viable values are below 16 can still be tested. The count rule is still one accepted run out of five attempts, so the detailed main-experiment logs report direct run values rather than averages over three successful runs. The program also prompts the user before proceeding to the next map configuration.
