\section{Interpretation Advice}

This file is a snapshot, not a substitute for \texttt{master\_config.py}. The important current design fact is that the project now uses manual branch-local raw-data persistence: solver-stage results are stored under \texttt{dev/outputs/raw\_mapf\_files/<map\_type>/}, while graphs/data exports and Pillow visualizations are regenerated separately on demand. Older branch roots in the previous top-level raw-data folders are migrated automatically when the branch is accessed again. In particular, the visualization-selection controls \texttt{num\_last\_runs\_to\_visualize\_jointly\_successful} and \texttt{num\_last\_runs\_to\_visualize\_independently\_successful} are intended to be changed without forcing a new MAPF recomputation, and one visualization-only execution now generates both output variants.
